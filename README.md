# لعبة الفاروق عمر بن الخطاب رضي الله عنه
إعداد المعلمة: **ميرفت أمين**

نسخة مبسطة لطلاب الصف الثالث، بدون صوت، وتحتوي على **15 سؤالًا فقط**.

## مميزات النسخة
- 15 سؤالًا فقط.
- جميع الأسئلة مرتبطة بالمحتوى الظاهر في الصور المرسلة.
- لا توجد معلومات مضافة من خارج الصفحات.
- الأسئلة تبدأ من الكنية واللقب والمولد والعمل والنشأة، ثم الإسلام والصفات والخلافة والفتوحات والوفاة.
- لا يوجد أي صوت أو نطق آلي.
- الطالب يكتب اسمه في شاشة البداية.
- الإجابات تطفو في السماء ويصوّب الطالب عليها.
- نقاط وتتابع وورود ونجوم عند الإجابة الصحيحة.
- يظهر رقم الصفحة التي أُخذت منها المعلومة.

## الرفع على GitHub Pages
ارفع جميع الملفات كما هي إلى جذر الـ Repository، ثم فعّل GitHub Pages من Settings > Pages.
