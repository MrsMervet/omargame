# لعبة الفاروق عمر بن الخطاب رضي الله عنه

لعبة تعليمية عربية جاهزة للرفع على **GitHub Pages**.

## الفكرة
- شاشة افتتاحية يكتب فيها الطالب اسمه.
- عنوان اللعبة: **لعبة الفاروق عمر بن الخطاب رضي الله عنه**.
- إعداد المعلمة: **ميرفت أمين**.
- سؤال يظهر أعلى الشاشة.
- الإجابات تطفو داخل السماء، والطالب يصوّب عليها.
- نقاط + تتابع للإجابات الصحيحة + دقة التصويب.
- مؤثرات ورود ونجوم عند الإجابة الصحيحة.
- أصوات مؤثرات مصنوعة داخل المتصفح بدون ملفات صوت خارجية.
- نطق وتشجيع عربي باستخدام Speech Synthesis إذا كان المتصفح يدعمه.
- جولتان: 15 سؤالًا أو 25 سؤالًا.
- شاشة نتيجة نهائية مع إمكانية الطباعة.
- متجاوبة مع الكمبيوتر والجوال والتابلت.

## الملفات
- `index.html` الواجهة.
- `style.css` التصميم والحركة.
- `questions.js` بنك الأسئلة.
- `game.js` منطق اللعبة والنقاط والصوت.
- `assets/favicon.svg` أيقونة الموقع.
- `.nojekyll` لضمان عرض الملفات كما هي على GitHub Pages.

## طريقة الرفع على GitHub Pages
1. أنشئ Repository جديدًا.
2. ارفع **كل الملفات والمجلدات كما هي** إلى الجذر.
3. من Settings → Pages.
4. اختر Deploy from a branch.
5. اختر الفرع `main` والمجلد `/root`.
6. اضغط Save وانتظر رابط الموقع.

## تعديل اسم المعلمة
ابحث داخل `index.html` عن:
`ميرفت أمين`

## تعديل الأسئلة
افتح `questions.js`.
كل سؤال يحتوي:
- `q`: نص السؤال.
- `choices`: الاختيارات.
- `a`: رقم الإجابة الصحيحة قبل خلط الاختيارات تلقائيًا.
- `fact`: معلومة قصيرة تظهر بعد الإجابة الصحيحة.

> ملاحظة: الأفضل تشغيل اللعبة من خلال GitHub Pages أو أي خادم محلي، وليس بفتح الملف مباشرة فقط، خصوصًا للحصول على أفضل توافق للصوت وملء الشاشة.
